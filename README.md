# Necrovix

Open `index.html` in a browser (keep all files in one folder). No install, no API key.

Pages: `index.html` ask box with cited answers, `platform.html` simulator (Discover, Plant, Optimise), `science.html` method and sources, `pricing.html` plans and contact.
Shared: `style.css`, `core.js` (logo, nav, model, live fetchers), `data.js` (snapshot data), `ask.js`, `platform.js`, `logo.svg`, `fx.js` (animations: network background, scroll reveal, typing placeholder, nav).
Live (needs internet): PubChem, Catalysis-Hub, OpenAlex. Snapshot values are indicative; edit `data.js` to refresh them.
